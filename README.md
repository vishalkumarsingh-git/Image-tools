# Programming Blitz. — Image Studio

A modern, responsive image-tools workspace.

## Current features

- Upload images using the file picker or drag and drop
- Live image preview with image dimensions
- Brightness, contrast, saturation and blur adjustments
- Rotate and flip controls
- Export as PNG, JPEG or WebP
- Export quality control
- Client-side processing for the current editing tools

## Run locally

This first version is a static website. Open `index.html` in a modern browser, or serve the repository with any static web server.

## Planned AI features

The interface includes entry points for Gemini-powered image enhancement, background tools and object removal. These features are not connected yet.

**API security:** Do not place a Gemini API key in browser-side JavaScript or commit it to this repository. AI integration should call a server-side endpoint, with the key stored in an environment variable or deployment secret.
